# Castrum Tactics

Castrum Tactics is a two-player, turn-based strategy game in development for Windows and Android. Players compete to control territory on a configurable 2D grid.

The Godot application runs a local two-player Unlimited Draft on a 7-by-5 demonstration map. The engine-independent domain also implements main-phase rules for future session integration.
