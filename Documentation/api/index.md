# API Reference

DocFX generates this reference from the application, domain, and AI C# projects. Use the sidebar to browse namespaces and types, and the headings on a type's page to find individual members.

- [CastrumTactics.Domain](xref:CastrumTactics.Domain) contains the board model, beginning with [`MapDefinition`](xref:CastrumTactics.Domain.MapDefinition) and [`BoardState`](xref:CastrumTactics.Domain.BoardState).
- [`PredefinedMapCatalog`](xref:CastrumTactics.Domain.PredefinedMapCatalog) enumerates [`PredefinedMap`](xref:CastrumTactics.Domain.PredefinedMap) entries, resolves identifiers, and supports reproducible random selection with a seeded source. See the [map format and catalog](../MapFormat.md).
- [`CpuDecisionEngine`](xref:CastrumTactics.AI.CpuDecisionEngine) synchronously returns legal [`CpuDecision`](xref:CastrumTactics.AI.CpuDecision) proposals tagged with the input snapshot's phase and session-scoped round ID. Share an engine across worker calls with an independent random source per call. [`CpuProfile`](xref:CastrumTactics.AI.CpuProfile) and [`CpuDifficultyProfiles`](xref:CastrumTactics.AI.CpuDifficultyProfiles) supply immutable tuning with separate phase limits and optional score gaps, configurable opening diversity, and [`CpuEvaluationWeights`](xref:CastrumTactics.AI.CpuEvaluationWeights) for scoring normalized [`CpuFeatures`](xref:CastrumTactics.AI.CpuFeatures). See the [CPU architecture](../CpuArchitecture.md).
- [`TerritoryAnalyzer`](xref:CastrumTactics.Domain.TerritoryAnalyzer) classifies a resolved board. Its [`TerritoryAnalysis`](xref:CastrumTactics.Domain.TerritoryAnalysis) exposes both secured totals. [`MainPhaseState`](xref:CastrumTactics.Domain.MainPhaseState) uses those totals for the final result and resolves a pair of player-tagged selections into a new board.
- [`IGameSession`](xref:CastrumTactics.Domain.Session.IGameSession) accepts [opening selections](xref:CastrumTactics.Domain.Session.OpeningSelection) and [main-phase commands](xref:CastrumTactics.Domain.Session.MainPhaseCommand), and publishes [`GameSessionSnapshot`](xref:CastrumTactics.Domain.Session.GameSessionSnapshot) updates. [`LocalGameSession`](xref:CastrumTactics.Domain.Session.LocalGameSession) implements local two-player coordination through final scoring.
- [`MatchConfiguration`](xref:CastrumTactics.Match.MatchConfiguration) defines immutable mode, human faction, and CPU difficulty. Pass it to [`Main`](xref:Global.Main) before scene initialization to override the editor defaults.
- [`BoardRenderer`](xref:Global.BoardRenderer) draws the session board, handles board selection, and exposes the exact grid rectangle. [`TerritoryScoreBanner`](xref:Global.TerritoryScoreBanner) displays the snapshot's `PlayerOneScore` and `PlayerTwoScore`. [`AnimatedBackground`](xref:Global.AnimatedBackground) provides the reusable viewport background with configurable motion.
